# daily-log

Claude Code のセッション履歴から、1 日 1 ファイルの日次ログを作るプラグイン。
日報を手で書かずに、作業の記録を積み上げることが目的。

## 中身

| 種類 | 名前 | 役割 |
|---|---|---|
| スキル | `daily-log` | 指定日(なければ未作成の日すべて)の日次ログを書く |
| スクリプト | `scripts/collect.mjs` | `~/.claude/projects/*/*.jsonl` から 1 日分の材料を集める(秘密情報は伏字)。未作成の日の列挙も行う |
| スクリプト | `scripts/schedule.sh` | 毎朝の自動実行を launchd に登録・解除する(macOS) |

## 日次ログの形

保存先に `YYYY-MM-DD.md` を 1 日 1 ファイルで作る。

- プロパティ: `日付` / `テーマ`(複数) / `セッション数`
- 本文: やったこと / 気づき・学び / 繰り返し出てきた作業

業務の固有情報(勤務先・人名・社内の数字・秘密情報)は書かず、学びの粒度に言い換える。

### 日付の区切り

プロンプトを打った時刻(ローカル時刻)で日を分ける。日をまたいだセッションは、それぞれの日に分けて数える。
夜遅くの作業も拾えるよう、自動実行は翌朝に前日分を作る。

### 重複と取りこぼし

- 同じ日のファイルがすでにあれば作らない(作り直したいときは「〇日の日次ログを作り直して」と頼む)
- 実行しなかった日があっても、次の実行で直近 14 日のうち未作成の日をまとめて作る
- 自動実行のセッション自身は、プロンプトの目印 `[daily-log:auto]` で集計から外す

## 設定

保存先はユーザーレベルの設定に書く。`~/.claude/CLAUDE.md` に 1 行足す(パスは自分の環境に合わせる):

```
- 日次ログの保存先: `<フォルダのパス>`
```

### 履歴の保存期間

Claude Code は `cleanupPeriodDays`(既定 30 日)より古いセッション履歴を消す。
自動実行は翌朝に動くので通常は問題ないが、30 日以上止めていた日の分は作れない。

## インストール

```
claude plugin install daily-log@hiroki-plugins
```

### 毎朝の自動実行(macOS)

インストール後、ターミナルで次を実行する(時刻は省略すると 07:00):

```
bash ~/.claude/plugins/marketplaces/hiroki-plugins/plugins/daily-log/scripts/schedule.sh install "<保存先>" 07:00
```

- 実体は `claude -p` を launchd から呼ぶだけ。ログは `~/Library/Logs/daily-log.log`
- 今すぐ 1 回動かす: `schedule.sh run` / 解除: `schedule.sh uninstall`
- スリープ中だった場合は起きたときに 1 回走る。電源が切れていた日は次回の実行で拾われる
