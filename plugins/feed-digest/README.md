# feed-digest

登録したブログの RSS/Atom フィードから新着を取り、日本語の要約ダイジェストを作るプラグイン。
ダイジェストでチェックを付けた記事だけ、次の実行で本文を Markdown として保存する。
全記事の本文は保存しない(積読と保存先の散らかりを避けるため)。

## 中身

| 種類 | 名前 | 役割 |
|---|---|---|
| スキル | `feed-digest` | 新着を取ってダイジェストを書く。チェック済みの本文保存・取得だけ・購読の追加も扱う |
| スクリプト | `scripts/feed.mjs` | フィードの取得・新着の判定・原文のキャッシュ・HTML から Markdown への変換(Node 標準のみ) |

## 使い方

Claude Code で次のように頼む。

- 「フィードの新着見せて」「〇〇の新着まとめて」 — チェック済みの本文を保存 → 新着を取得 → ダイジェストを書く
- 「新着を取得だけしておいて」 — 要約は書かずに新着を溜める(投稿の多いフィードの取りこぼし対策)
- 「チェックした記事保存して」 — 本文の保存だけ
- 「この RSS も購読に追加して」 — feeds.json に足す

## 保存先の形

```
<保存先>/
  feeds.json                         購読するフィード
  <フィードid>/
    digest/YYYY-MM-DD.md             ダイジェスト(要約3行・観点の一言・おすすめ度・チェックボックス)
    articles/YYYY-MM-DD-<記事id>.md  チェックした記事の本文(先頭に「自分メモ」欄)
    .feed-cache/                     取得済みID・原文・新着リスト(触らない)
```

- ダイジェストの `- [ ] 本文を保存（id: …）` にチェックを付けておくと、次の実行で本文が保存され、
  行が `保存済み → [[…]]` に変わる(Obsidian のリンク形式)
- 原文はキャッシュしてあるので、フィードから消えた記事でもチェックすれば保存できる
- フィードに抜粋しか載っていないブログは、抜粋だけが保存される(記事ページは取りに行かない)

## 設定

リポジトリには購読先も保存先も入れない。

1. `~/.claude/CLAUDE.md` に 1 行足す(パスは自分の環境に合わせる):

   ```
   - フィードダイジェストの保存先: `<フォルダのパス>`
   ```

2. `<保存先>/feeds.json` を置く(「この RSS を購読に追加して」と頼めば作ってもらえる):

   ```json
   {
     "feeds": [
       {
         "id": "example-blog",
         "name": "Example Blog",
         "url": "https://example.com/feed.xml",
         "perspective": "実務でどう使えるか"
       }
     ]
   }
   ```

   - `id`: 英数字・`-`・`_`。フォルダ名になる
   - `perspective`: ダイジェストに添える一言の観点(省略時は「実務でどう使えるか」)

## インストール

```
claude plugin install feed-digest@hiroki-plugins
```

Node.js 18 以上が要る(フィードの取得に標準の `fetch` を使う)。

### 定期実行

自動実行のときはプロンプトに `[feed-digest:auto]` を入れると、質問せずに最後まで進める。

```
claude -p "[feed-digest:auto] フィードの新着でダイジェストを作って"
```
