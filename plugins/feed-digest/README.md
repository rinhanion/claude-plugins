# feed-digest

購読している RSS/Atom フィードの新着を日本語のダイジェストにし、チェックした記事だけ本文を Markdown で保存するプラグイン。
ブログの新着を追う手間を減らし、読みたい記事だけを手元に残すことが目的。

## 中身

| 種類 | 名前 | 役割 |
|---|---|---|
| スキル | `feed-digest` | 新着の取得 → ダイジェスト(要約3行・視点の一言・おすすめ度・チェックボックス)を書く → チェックした記事を保存 |
| スクリプト | `scripts/feed.mjs` | フィードの取得・解析、取得済み記事のキャッシュ、本文の Markdown 変換と保存(Node 標準のみ) |

`feed.mjs` のコマンド:

| コマンド | 内容 |
|---|---|
| `fetch --dir <保存先> [--feed <id>]` | まだ見ていない記事だけを JSON で出す |
| `list --dir <保存先> [--feed <id>] [--new]` | キャッシュ済みの記事を JSON で出す(`--new` でダイジェスト未作成のみ) |
| `clear-new --dir <保存先>` | ダイジェストを書き終えた記事の new 印を外す |
| `save --dir <保存先> --digest <file>` | `[x]` の行の記事を保存し、その行を `保存済み → [[…]]` に置き換える |

RSS 2.0 と Atom の両方を読む。本文は `content:encoded` → `content` → `description`/`summary` の順に取る。

## 保存先の構成

```
<保存先>/
  feeds.json                             購読フィード
  digests/YYYY-MM-DD.md                  ダイジェスト
  articles/<id>/YYYY-MM-DD-<タイトル>.md  保存した記事の本文
  .cache/<id>.json                       取得済み記事の ID と原文
```

- 取得済みの記事はキャッシュに残るので、2 回目以降は新着だけがダイジェストに載る
- フィードから消えた古い記事も、一度取得していればチェックして保存できる
- 保存した記事は Obsidian などのウィキリンク(`[[…]]`)でダイジェストからたどれる

## 設定

保存先はユーザーレベルの設定に書く。`~/.claude/CLAUDE.md` に 1 行足す(パスは自分の環境に合わせる):

```
- フィードダイジェストの保存先: `<フォルダのパス>`
```

購読フィードは `<保存先>/feeds.json` に書く:

```json
[
  { "id": "example", "name": "Example Blog", "url": "https://example.com/feed.xml", "lens": "自分のチームに持ち帰れる話か" }
]
```

- `id`: 英数字・`_`・`-`。保存フォルダ名とチェック行の目印に使うので、あとから変えない
- `lens`: 要約に添える視点(省略可)

## インストール

```
claude plugin install feed-digest@hiroki-plugins
```

## 使い方

- 「フィードの新着まとめて」→ ダイジェストができる
- ダイジェストで読みたい記事の `- [ ] 保存する` にチェックを入れる
- 「チェックしたのを保存して」→ 本文が `articles/` に保存される
