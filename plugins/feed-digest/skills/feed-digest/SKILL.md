# フィードダイジェスト

購読フィードの新着を、読むか決めるためのダイジェストにする。
読みたい記事にチェックを入れてもらい、その記事だけ本文を手元に残す。

スクリプトは `${CLAUDE_PLUGIN_ROOT}/scripts/feed.mjs`。以下 `feed.mjs` と書く。

## 設定を探す

保存先はスキルの中には無い。ユーザーレベルの設定に書かれている。

- 探し先: `~/.claude/CLAUDE.md`、開いているフォルダの `CLAUDE.md`
- 書き方の例: `- フィードダイジェストの保存先: <フォルダのパス>`

見つからなければ保存先を聞き、`~/.claude/CLAUDE.md` に上の 1 行を足してよいか確認する。

購読フィードは `<保存先>/feeds.json`。無ければ、購読したいフィードを聞いて作る。

```json
[
  { "id": "example", "name": "Example Blog", "url": "https://example.com/feed.xml", "lens": "自分のチームに持ち帰れる話か" }
]
```

- `id`: 英数字・`_`・`-`。保存フォルダ名とチェック行の目印に使うので、あとから変えない
- `lens`: 要約に添える視点(省略可)。「購読に追加して」と言われたら、なぜ読みたいかを聞いて `lens` にする

## 新着のダイジェストを書く

1. `node feed.mjs fetch --dir <保存先>` を実行する(1 本だけなら `--feed <id>`)
   - 出力は JSON。フィードごとに今回はじめて見た記事(`key` / `title` / `link` / `published` / `excerpt`)が入る
   - `error` のあるフィードは、ダイジェストの最後に「取得できなかったフィード」として一言書く
2. `total` が 0 なら「新着なし」と伝えて終える(ファイルは作らない)
3. `<保存先>/digests/YYYY-MM-DD.md`(今日の日付)に書く。同じ日のファイルがあれば末尾に追記する
4. 書き終えたら `node feed.mjs clear-new --dir <保存先>` を実行する

書いている途中で失敗したら、`node feed.mjs list --dir <保存先> --new` で同じ記事をもう一度取り出せる。

### ダイジェストの形

```markdown
# フィードダイジェスト YYYY-MM-DD

## <フィードの name>

### [<記事タイトル>](<link>)
<published> ・ おすすめ度 ★★☆

- <要約1行目>
- <要約2行目>
- <要約3行目>

> 視点: <lens にもとづく一言>

- [ ] 保存する <!-- feed-digest:<フィードの id>/<key> -->
```

- 要約は `excerpt` に書かれていることだけで 3 行。英語の記事も日本語で書く。推測で足さない
- 視点は `lens` に照らして「何に使えそうか / 何が引っかかるか」を 1 文。`lens` が無ければ「読む価値の一言」にする
- おすすめ度は `lens` との近さと中身の濃さで ★☆☆〜★★★。宣伝・告知だけの記事は ★☆☆
- チェック行の `<!-- feed-digest:… -->` は保存に使う目印なので、形を変えずにそのまま書く
- 記事の順番はフィード内で新しい順

書き終えたら、ファイルの場所と、フィードごとの件数・★★★ の記事タイトルを短く報告し、
「読みたい記事にチェックを入れたら『保存して』と言ってください」と添える。

## チェックした記事を保存する

「保存して」「チェックしたのを保存」と言われたら:

1. 対象のダイジェストを決める(指定がなければ `digests/` の一番新しいファイル)
2. `node feed.mjs save --dir <保存先> --digest <ダイジェストのパス>` を実行する
   - `[x]` の行の記事だけ、本文を `<保存先>/articles/<id>/YYYY-MM-DD-<タイトル>.md` に保存する
   - その行は `- 保存済み → [[<ファイル名>]]` に置き換わる。チェックしていない行はそのまま
   - フィードから消えた記事も、一度取得していればキャッシュから保存できる
3. 保存した記事のタイトルとファイルを報告する。`errors` があれば、どの行が保存できなかったか伝える

本文の Markdown はスクリプトが変換したまま残す(要約や書き換えをしない)。
