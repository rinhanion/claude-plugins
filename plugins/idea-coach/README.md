# idea-coach

アプリ・Webサービスのアイデアをストックするための壁打ち相手さんプラグイン。[claude-plugins](../../README.md) マーケットプレイスの1つ。

## 何ができるか

- 新しいアイデアを話すと、自然な会話で深掘りしながら `idea-stock.md` に自動で記録していく(日常づかいの壁打ち相手)
- 「一覧見せて」「あのアイデアどうなってたっけ」で、ストックの中身を見返せる
- 「コーチとして詰めて」「本気でこのアイデア考えたい」と言うと、専属のコーチエージェントが1つのアイデアの一番弱いところに絞って厳しく問い詰め、セッションの最後に必ず次のアクション+期限を引き出して記録する

## 構成

| コンポーネント | 種類 | 役割 |
|---|---|---|
| `idea-stock` | Skill | 日常会話の中で自動発動する、気軽な壁打ち相手。アイデアの記録・一覧・見返しを担当 |
| `idea-coach` | Agent | 明示的に呼び出したときだけ登場する、高強度の1点集中コーチングセッション |

## セットアップ

インストールするだけで動く。追加のAPIキーやMCP連携は不要。

## 保存先について

アイデアの記録(`idea-stock.md`)は、実行環境に応じて以下の優先順で保存先を選ぶ(詳細は `skills/idea-stock/SKILL.md` を参照):

1. 接続されているローカルフォルダ直下
2. Artifactツールで永続化されたMarkdownページ(タイトル「アイデアストック」)
3. どちらも使えない場合はセッション内の作業ディレクトリ(この場合は都度ファイルを受け取って自分で保管する必要がある)

## 使い方の例

- 「英会話の宿題管理アプリってニーズあると思う?壁打ちに付き合ってほしい」
- 「アイデアストックの中身見せて」
- 「確定申告自動化のやつ、コーチモードで本気で詰めてほしい」
