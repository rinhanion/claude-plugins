# kaigo-dx-knowledge

介護DXの情報をNotionの「介護DXナレッジ」データベースに蓄積するプラグイン。[claude-plugins](../../README.md) マーケットプレイスの1つ。

## 何ができるか

- URLや会話で出た内容を渡して「介護DXナレッジに登録して」と伝えると、要約してデータベースに1件登録する
- `出典URL` で既存ページを検索し、登録済みなら新規作成せずその旨を伝える
- `カテゴリ`・`対象企業` は内容から推定し、判断が割れるときは登録前に確認する
- URLを取得できない環境(Claudeアプリ側など)では、貼り付けテキストや会話内容から要約する

## 構成

| コンポーネント | 種類 | 役割 |
|---|---|---|
| `knowledge-add` | Skill | 情報を要約し、「介護DXナレッジ」データベースに1件登録する |

## セットアップ

Notion MCP(データベース `介護DXナレッジ` への読み書き権限)が必要。Notion MCPが無い環境ではこのスキルは動かない。

## 使い方の例

- 「この厚労省のページ、介護DXナレッジに登録して」(URLを添える)
- 「さっきのSOMPOケアの話、ナレッジに溜めて」
- 「この記事をナレッジ化して」(本文を貼り付ける)
