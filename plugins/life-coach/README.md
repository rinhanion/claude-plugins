# life-coach

伴走型の人生コーチ(壁打ち役)のプラグイン。答えを与えるより、問いで本人の気づきを引き出す。
Claude Code(Remote Control 含む)とアプリのチャットの両方で同じように使えることを狙っている。

## 中身

| 種類 | 名前 | 役割 |
|---|---|---|
| スキル | `coach` | 仕事・キャリア/副業・発信・お金/生活・家族・健康の相談、目標の見直し、週次ふりかえりに伴走する |
| サブエージェント | `life-coach-analyst` | 材料置き場の記録を読み、事実にもとづく所見を返す(Read / Glob / Grep のみ) |

アプリ・サービスのアイデアの壁打ちは [idea-coach](../idea-coach/README.md) の担当。

## 材料置き場

判断軸・判断ログ・目標・日次ログ・ふりかえりといった個人の材料は、**このリポジトリには入れない**。
リポジトリの外にある「材料置き場」(任意のフォルダ)に置き、その場所をユーザーレベルの設定に書いておく。
スキルとサブエージェントはそれを探して読むだけ。

### 場所の書き方

Claude Code では `~/.claude/CLAUDE.md` に 1 行足す(パスは自分の環境に合わせる):

```
- 人生コーチの材料置き場: `<材料置き場のパス>`(ルールは中の CLAUDE.md に従う)
```

アプリのチャットでは、個人設定(好み)欄かメモリに同じ内容を書く。
チャットからファイルが読めない場合、コーチはメモリと会話から前提をつかみ、決めたことは下書きとして返す。

### 材料置き場の中身(例)

```
<材料置き場>/
  CLAUDE.md          読み方・書き方のルール(判断ログの書式など)
  現在地.md          いまの状況のまとめ
  判断軸/
  判断ログ/
  目標/
  日次ログ/          エネルギー(1〜5)・学習時間などを記録
  ふりかえり/
```

フォルダ名や構成は自由。材料置き場の `CLAUDE.md` に書いたルールが優先される。空のフォルダがあってもよい。

## インストール

```
claude plugin install life-coach@hiroki-plugins
```

「コーチして」「壁打ちしたい」「相談したい」などで発動する。
