# marketplace-ping

[claude-plugins](../../README.md) マーケットプレイスの疎通確認用プラグイン。

## 何のためのものか

新しいプラグインを追加したときに、「マーケットプレイスに登録 → `git push` → `/plugin install` → スキルが発動する」という一連の流れがちゃんと通っているかを確かめるための、中身が最小限のプラグイン。実務的な機能はない。

## 構成

| コンポーネント | 種類 | 役割 |
|---|---|---|
| `ping` | Skill | 「疎通確認して」で発動し、プラグインが読み込まれていることと今日の日付を返して `pong 🏓` と言うだけ |

## 使い方

```
/plugin install marketplace-ping@hiroki-plugins
```

インストール後、会話で「疎通確認して」「ping」などと言うと `ping` スキルが発動する。確認が済んだらアンインストールしてよい。
