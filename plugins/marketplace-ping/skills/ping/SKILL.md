# ping スキル

これは `claude-plugins` マーケットプレイスの配信・インストール・発動が一通り機能しているかを確認するためだけのスキル。

## やること

ユーザーが疎通確認を求めたら、次の内容を返す:

1. `marketplace-ping` プラグインの `ping` スキルが読み込まれて発動したこと
2. 今日の日付(環境から取得できる場合)
3. 一言 `pong 🏓`

それ以上の作業や質問はしない。確認が取れたら「マーケットプレイスの配信からスキル発動まで疎通OK」と伝えて終了する。
