# note-draft

過去の note 記事から抽出した本人（`hiroking22`）の文体で、note の**下書き**記事を生成するプラグイン。

## 何をするか

- トピックや箇条書きメモ、または Notion「ブログのネタ帳」のストックを渡すと、本人が書いたような note 記事の本文（Markdown）を組み立てる
- タイトル案を3つ出し、未確認の事実は `（★確認）` を残して質問する
- 確認が取れたら note-api MCP の `post-draft-note` で**下書き投稿**（公開はしない）
- ネタ帳起点で書いた場合は Notion のページにも書き戻す（Notion MCP がある場合）

## 収録スキル

| スキル | 発動タイミング |
|---|---|
| `note-draft` | 「noteの下書き書いて」「この話を記事にして」「ネタ帳から記事書いて」など、note/ブログの記事本文を書いてほしいとき |

## 文体プロファイル

`skills/note-draft/STYLE.md` に同梱（静的）。公開記事75本のうち16本を全文分析して作成。
声のルール（トピック別レジスター）、構成の型、表記のクセ、タイトルの型、記事タイプ別テンプレート6種、固有名詞リストを含む。

**文体を更新したいときは、このリポジトリで `STYLE.md` を直接編集する**（自動再学習はしない）。

## 前提

- 下書き投稿には note-api MCP（`post-draft-note`）が必要。無い環境では最終Markdownを出力するだけになる
- ネタ帳連携には Notion MCP が必要。無い環境ではネタの中身を貼ってもらう運用になる
