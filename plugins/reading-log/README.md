# reading-log

Notionの「読書リスト」データベースに読書の開始を記録するプラグイン。[claude-plugins](../../README.md) マーケットプレイスの1つ。

## 何ができるか

- 「〜を読み始めます」「今日から〜を読む」と伝えると、Notionの「読書リスト」データベースを検索し、見つかった本の `ステータス` を `読んでる` に・`読み始め` を今日の日付に更新する
- リストに無い本なら、確認のうえ新規ページとして追加する
- 表記ゆれ・複数候補があるときは、誤って別の本を更新しないよう必ず確認する

## 構成

| コンポーネント | 種類 | 役割 |
|---|---|---|
| `reading-start` | Skill | 読書開始のメッセージをきっかけに、Notionの読書リストを検索・更新する |

## セットアップ

Notion MCP(データベース `読書リスト` への読み書き権限)が必要。Notion MCPが無い環境ではこのスキルは動かない。

## 使い方の例

- 「『エッセンシャル思考』を読み始めます」
- 「今日から人月の神話を読む」
- 「読書を始めます、タイトルは推測できないと思うので聞いてください」
