# reading-log

読書の開始や読書中の気づきを、1冊1ファイルのMarkdownの置き場(Obsidian の vault など)に記録するプラグイン。[claude-plugins](../../README.md) マーケットプレイスの1つ。

## 何ができるか

- 「〜を読み始めます」「今日から〜を読む」と伝えると、置き場で本のファイルを探し、frontmatter の `状態` を `読んでる` に・`読み始め` を今日にする
- 置き場に無い本なら、確認のうえひな形で新しいファイルを作る
- 表記ゆれ・複数候補があるときは、誤って別の本を書き換えないよう必ず確認する
- 読書中の気づき・感想を話した後に「メモしておいて」と伝えると、直前の会話から本人のつぶやきとClaudeの補足を切り出し、読んでいる本の読書メモに日付の見出しで追記する

読了の記録や読後のふりかえりはこのプラグインに入れていない。置き場の `CLAUDE.md` に手順を書いておけば、そちらに従う。

## 構成

| コンポーネント | 種類 | 役割 |
|---|---|---|
| `reading-start` | Skill | 読書開始のメッセージをきっかけに、本のファイルの状態と読み始め日を書く |
| `reading-note` | Skill | 読書中の気づき・感想の会話をきっかけに、読んでいる本の読書メモに追記する |

## セットアップ

置き場の場所を、ユーザーレベルの `~/.claude/CLAUDE.md` に1行書く。

```
- 読書記録の置き場: <フォルダのパス>
```

書き方の決まり(ひな形の場所・プロパティ名・読書メモの形など)は、置き場か、その上のフォルダの `CLAUDE.md` に書く。スキルはそれを読んで従い、決まりが無ければスキル側の初期値で書く。

## 使い方の例

- 「『エッセンシャル思考』を読み始めます」
- 「今日から人月の神話を読む」
- (読書中の気づきについて話した後に)「これも読書記録として残したい」「読書メモに残して」
