# reading-note スキル

読書記録の置き場で読んでいる本のノート(1冊1ファイルのMarkdown)に、会話から生まれた気づきや感想を読書メモとして追記する。

## 置き場を探す

置き場の場所はこのスキルの中には無い。ユーザーレベルの設定に書かれている。

- 探し先: `~/.claude/CLAUDE.md`(そこから `@` で読み込まれるファイルを含む)、開いているフォルダの `CLAUDE.md`
- 書き方の例: `- 読書記録の置き場: <フォルダのパス>`
- 設定が見つからない、または置き場のファイルを読めない環境なら、書かずにそう伝え、メモの文面だけを返す(あとで貼れるように)

## 置き場の決まりに従う

置き場、またはその上のフォルダに `CLAUDE.md` があれば、書く前に読む。読書メモの見出し・日付の付け方・本人の言葉とClaudeの補足の書き分け方は、そちらが正本。このスキルの下の内容とぶつかったら、置き場の決まりを優先する。同じノートに既に読書メモがあれば、その形にも合わせる。

置き場に決まりが無いときは、次を初期値にする。

- 追記先は本文の `# 読書メモ` の末尾。見出しが無ければノートの末尾に作る
- 1回分の形(日付はAsia/Tokyoの今日、同じ日の2回目以降は `(2)` のように番号を付ける):

```
## YYYY-MM-DD

> 🗣️ {ユーザーのつぶやき}

💬 Claude
- {Claudeの補足、箇条書き}
```

## 手順

### 1. 対象の本を特定する

置き場で frontmatter の `状態` が `読んでる` のファイルを探す。

- 1件: それを対象にする
- 複数: どの本のことか一言で確認する(候補のタイトルを挙げてよい)
- 0件: 読んでいる本が無い旨を伝え、どの本のことか聞く

### 2. 直前の会話から切り出す

- **つぶやき**: ユーザーが話した気づき・疑問・感想。本人の言葉をなるべくそのまま残す。「〜と思った」を「〜」にするような圧縮はしない
- **補足**: それに対してClaudeが返した説明・関連知識・答え。前置きを削り、要点を箇条書きにする

本人の言葉とClaudeの補足は混ぜない。話題が複数あれば直近のひとまとまりを対象にし、どこまでか曖昧なら一言確認する。

### 3. 追記する

- ノートを読んでから、読書メモの末尾に1回分を足す
- 追記する場所以外(frontmatter・他の見出しの本文)には触れない

### 4. 返信は簡潔に

「『〇〇』の読書メモに追記しました」程度でよい。

## やらないこと

- frontmatter(`状態`・`読み始め`・`読了` など)を書き換えること
- 読書開始・読了の記録や読後のふりかえり(開始は reading-start、それ以外は置き場の手順があればそちらに従う)
- ユーザーのつぶやきを要約しすぎて言葉のニュアンスを失うこと
