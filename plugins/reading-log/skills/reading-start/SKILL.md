# reading-start スキル

読書記録の置き場にある本のノート(1冊1ファイルのMarkdown)に、読書開始を記録する。

## 置き場を探す

置き場の場所はこのスキルの中には無い。ユーザーレベルの設定に書かれている。

- 探し先: `~/.claude/CLAUDE.md`(そこから `@` で読み込まれるファイルを含む)、開いているフォルダの `CLAUDE.md`
- 書き方の例: `- 読書記録の置き場: <フォルダのパス>`
- 設定が見つからない、または置き場のファイルを読めない環境なら、書かずにそう伝える(「読書記録の置き場が見つからないので記録できません」)

## 置き場の決まりに従う

置き場、またはその上のフォルダに `CLAUDE.md` があれば、書く前に読む。ひな形の場所・プロパティ名・状態の値・本文の見出しなど、書き方の決まりはそちらが正本。このスキルの下の内容とぶつかったら、置き場の決まりを優先する。

置き場に決まりが無いときは、次を初期値にする。

- 1冊1ファイル。ファイル名は本のタイトル
- frontmatter: `状態`(`読みたい` / `読んでる` / `読了`)、`著者`、`出版社`、`読み始め`(`YYYY-MM-DD`)、`読了`(`YYYY-MM-DD`)
- 本文の見出し: `# 読書メモ`

## 手順

### 1. 本のタイトルを確認する

- メッセージにタイトルが含まれていればそれを使う
- 含まれていなければ、どの本を読み始めるか一言で聞く(長い質問攻めにはしない)

### 2. 置き場で本のファイルを探す

ファイル名(と frontmatter にタイトルがあればそれ)が一致・部分一致するものを探す。表記ゆれ(サブタイトルの有無・全角半角・括弧の違いなど)で近いものがあれば候補として出してよい。候補が複数・曖昧なときは、誤って別の本を書き換えないよう必ず確認する。

### 3. 見つかった場合

- frontmatter の `状態` を `読んでる` に、`読み始め` を今日の日付(Asia/Tokyo、`YYYY-MM-DD`)にする
- すでに `読んでる` のときは、読み始め日を上書きしてよいか一言確認する
- `読了` のときは、再読として扱ってよいか確認してから書き換える
- 書き換えるのは上の2つのプロパティだけ。本文や他のプロパティには触れない

### 4. 見つからなかった場合

- 置き場に無い旨を伝え、新しく作ってよいか確認する
- OKなら、置き場の決まりにあるひな形(無ければ上の初期値)で作る。ひな形に日付の差し込み(`{{date:YYYY-MM-DD}}` など)があれば、今日の日付に置き換えて書く
  - `状態`: `読んでる`、`読み始め`: 今日
  - 著者・出版社はユーザーが自然に言及していれば入れてよいが、無理に聞き出さない

### 5. 返信は簡潔に

「『〇〇』を読んでるにして、読み始めを今日にしました」+ファイルのパス程度でよい。

## やらないこと

- 読了の記録や読後のふりかえり(置き場に手順があればそちらに従う。このスキルの範囲外)
- 置き場の決まりに無い状態の値を使うこと
- 表記ゆれ・複数候補があるまま確認なしで書き換えること
