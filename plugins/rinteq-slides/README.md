# rinteq-slides

学会・カンファレンス発表用の個人スライドテンプレート「rinteq」を適用してpptxスライドを生成するプラグイン。

## 何をするか

- ネイビー(`#16233F`)+ターコイズ(`#00B4A6`)の配色、右上を面取りしたモノグラムロゴ、Noto Sans JPのタイポグラフィを使った、学会・カンファレンス発表向けのデフォルトスライド構成でpptxを生成する
- 生成した`.pptx`はGoogle Driveにアップロードすればそのままレイアウトを保ったままGoogle Slidesで開ける
- pptxgenjsの実装・QA・トラブルシューティングは基盤の`pptx`スキルに従い、このプラグインは配色・ロゴ・タイポグラフィ・スライド構成などの個人テンプレートだけを提供する

## 収録スキル

| スキル | 発動タイミング |
|---|---|
| `rinteq-slides` | 「学会発表のスライド作って」「カンファレンスの資料作って」「いつものテンプレートで」「rinteqで」のように、自分用の発表スライドを作ってほしいとき |

## 前提

- 基盤となる`pptx`スキル(pptxgenjsの実装・QA)と併用する
- ロゴ画像は`skills/rinteq-slides/assets/logo/`に同梱(`monogram.png` / `monogram_outline.png` とそれぞれのSVG版)
