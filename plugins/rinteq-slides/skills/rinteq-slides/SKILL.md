# rinteq スライドテンプレート

学会・カンファレンス発表用の個人スライドテンプレート。このスキルが定義するのは*見た目(ビジュアルアイデンティティ)とスライド構成*だけ。実際に`.pptx`を組み立てる際のpptxgenjsの実装・QA・画像変換などの手順は、基盤となる**pptx**スキルを併せて読み、そちらに従う(ここでは重複させない)。

## スライドを作るときの流れ

1. コードを書く前に、まずこのファイルを最後まで読む
2. 実際に`.pptx`を生成する部分は、基盤の`pptx`スキルのpptxgenjsワークフロー・注意点・QAプロセス(`validate.py`、LibreOfficeレンダリングによる目視QA)に従う
3. 下記の配色・タイポグラフィ・ロゴ・スライド構成を適用する
4. 基盤スキルの手順でQAを行い、さらに日本語テキストが正しくレンダリングされているか全スライドを目視確認してから完了とする(タイポグラフィの項を参照)
5. 最終ファイルは`.pptx`として保存する。Google SlidesはこのファイルをGoogle Driveにアップロードするだけでそのまま開け、体裁もそのまま保たれる旨をユーザーに伝える(作り直しは不要)

## 配色

| 役割 | 色名 | Hex(pptxgenjsでは`#`なし) |
|---|---|---|
| プライマリ/インク | ネイビー | `16233F` |
| アクセント(控えめに使う) | ターコイズ | `00B4A6` |
| 背景(セカンダリ) | ライトグレー | `F2F4F6` |
| 背景(ベース) | ホワイト | `FFFFFF` |
| 本文テキスト | チャコール | `2A2A2A` |

- ネイビーを基調にする(タイトル・セクション・クロージングスライドの背景、見出し、本文テキスト)。ターコイズは**あくまで鋭いアクセント**として、チャートの系列色、強調したい数字・キーワードの一部、細い区切り線、アイコンの塗り、ページ番号程度に留める。段落の本文テキストにターコイズは使わない — 白背景での視認性が低く、小さいサイズでは読みにくくなる
- コンテンツスライド: 白またはライトグレーの背景に、ネイビー/チャコールのテキスト(ライトテーマ)
- タイトル・セクション区切り・クロージングスライド: ネイビー背景に白テキスト、ターコイズをアクセントに(ダークテーマ) — 基盤pptxスキルのデザインガイドにある「サンドイッチ構造」
- 他の色は追加しない。チャートで複数系列の色が必要な場合も、新しい色相を足すのではなくネイビーとターコイズの濃淡で対応する

## ロゴ

`assets/logo/`に、同じ面取りモノグラム(右上の角を斜めに落とした正方形の中に、小文字のターコイズの「r」)から作った2種類が入っている:

- `monogram.png`(ネイビーの形+ターコイズの「r」) — **ライト背景**用。すべてのコンテンツスライドの右下隅に小さく(0.4"×0.4"程度)、端から0.3"の位置に配置する
- `monogram_outline.png`(白のアウトライン+ターコイズの「r」) — **ネイビー背景**用(タイトル、セクション区切り、クロージングスライド)。ここではブランドを意識的に見せる場面なので、やや大きく(1"〜1.5")表示してよい — 例えばタイトルブロックの近くや、クロージングスライドの中央など
- タイトルスライドでは、ロゴとワードマークを組み合わせる。ワードマークは画像ではなく**ネイティブテキスト**で: `rinteq`をLiberation Sans Bold(またはArial Bold)、背景に応じてネイビーまたは白、字間を詰めて(`charSpacing: -1`)表示する。小さく、控えめに — 主役は発表タイトルであってブランドではない
- ロゴファイルの再配色・引き伸ばし・エフェクト追加(用意されているもの以外のシャドウ・アウトライン)は行わない

面取りされた角の形は、このデッキで繰り返し使う**唯一のビジュアルモチーフ**(基盤スキルの「ビジュアルモチーフを1つ決めて徹底する」というガイドに沿う)。他の場所でもこのモチーフをさりげなく反響させることはあっても(画像フレームやアイコンコンテナの角を同じように1つ落とすなど)、2つ目のモチーフを追加しない。タイトルの下にカラーバー・アクセントの帯・アンダーラインは付けない — 基盤スキルが「AIスライドっぽさが出る要素」として挙げているもので、このテンプレートは余白とロゴのモチーフだけで済ませることで、それらを一切使わない

## タイポグラフィ

デッキは**日本語**。フォントは**Noto Sans JP**を使う(タイトル・見出しはBold、本文はRegular) — Google FontsのファミリーでGoogle Slidesがネイティブに、どの環境でも一貫してレンダリングしてくれる。このサンドボックスにも`Noto Sans CJK JP`がインストールされているため、LibreOfficeでのQAプレビューも実際の見え方と一致する。これにより、CJKテキストには適用されない基盤スキルのLatin向けセーフフォントリストを気にする必要がなくなる。

それ自体で強調を持つラテン文字・数字(大きめの数値の見せ場、`rinteq`のワードマーク、英語の参考文献など)には、ここにインストール済みでArialと計量的に等価なLiberation Sansを使えば安全。

| 要素 | サイズ | ウェイト |
|---|---|---|
| スライドタイトル | 32〜36pt | Bold |
| セクション見出し | 20〜22pt | Bold |
| 本文テキスト | 16〜18pt | Regular(日本語テキストは14ptだと詰まって見えるため、基盤スキルのデフォルトより大きめにする) |
| キャプション/フッター/ページ番号 | 10〜11pt | Regular |

本文・リストは左揃え、タイトルとタイトルスライドのブロックのみ中央揃えにする。最小マージンは0.5"、コンテンツブロック間は0.3"〜0.5"を保ち、全体を通して一貫させる。

## スライド構成(デフォルト)

まだ本人固有の決まった構成は定まっていないため、学会・カンファレンス発表向けの妥当なデフォルトとして以下を使い、実際の発表内容に応じてスライド数・内容を調整する(内容を無理に型にはめ込まない):

1. **表紙(Title)** — ネイビー背景。発表タイトル(大きく、白)、発表者名、所属、学会名・日付(小さめ、ターコイズまたは薄い白)。ワードマークは小さく隅に
2. **目次/アジェンダ** — ライト背景。番号付きのセクション、数字はターコイズ。番号バッジと見出しテキストは同じ行の`y`を基準にし、バッジの高さ(`h`)と見出しテキストボックスの高さ(`h`)を揃えたうえで見出し側に`valign: "middle"`を指定する(または双方の中心yが一致するよう座標を計算する)ことで、横のラインが縦方向に中央揃えになるようにする
3. **背景・課題(Background / Motivation)** — ライト背景。2カラムまたはアイコン+テキストで、課題を明確に述べる
4. **手法(Method / Approach)** — ライト背景。ネイビーの図形+ターコイズでキーステップを強調した図やプロセスフロー
5. **実験・結果(Results)** — ライト背景。ネイティブなpptxチャート(`addChart`)、ネイビー/ターコイズの系列色、チャート1枚につき伝えたいことを1つに絞る
6. **考察(Discussion)** — ライト背景
7. **まとめ(Conclusion)** — ネイビー背景(タイトルスライドと対をなす)。2〜4個のキーポイント、目玉となる数字があれば大きく見せる
8. **参考文献(References)** — ライト背景、やや小さめの文字(11〜12pt)、ネイビー
9. **謝辞・Thank you** — ネイビー背景、モノグラムのアウトラインロゴを大きく中央に、必要なら連絡先も

コンテンツ(ライト背景)スライドは、基盤スキルのルールに従い必ず1つ以上のビジュアル要素(チャート、図、丸囲みアイコン、画像)を入れる — プレーンなタイトル+箇条書きだけのスライドは作らない。
