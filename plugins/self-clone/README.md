# self-clone

本人の判断軸と好みを、どのプロジェクトの Claude Code からも使えるようにするプラグイン。

## 中身

| 種類 | 名前 | 役割 |
|---|---|---|
| スキル | `self-clone` | 判断の相談・UI/技術選定/設計の好み・仕事の進め方の場面で、判断軸・判断ログ・好みを読んで案の根拠にする。「好みに残して」「判断ログに残して」で置き場に書く |

問いで気づきを引き出す人生相談の伴走は [life-coach](../life-coach/README.md)、
アイデアの壁打ちは [idea-coach](../idea-coach/README.md)、文体は [note-draft](../note-draft/README.md) の担当。

## 置き場

判断軸・判断ログ・好みは **このリポジトリには入れない**。リポジトリの外の置き場(任意のフォルダ)に置き、
その場所をユーザーレベルの設定に書いておく。書き方の手順も置き場の `CLAUDE.md` に書き、スキルはそれに従う。

### 設定の書き方

`~/.claude/CLAUDE.md` に置き場の場所を書く。短い要約ノートを置き場に作り、`@` で取り込んでおくと、
スキルが呼ばれない場面(ちょっとした相談など)でも判断軸と好みが効く。

```
判断軸と好みの正本は <置き場のパス>(self-clone プラグインが使う。書き方のルールは同じフォルダの CLAUDE.md に従う)。

@<置き場のパス>/<要約ノート>.md
```

他のプロジェクトから書き込むときに毎回許可を聞かれないよう、`~/.claude/settings.json` の
`permissions.allow` に置き場への `Read(//<置き場のパス>/**)` と `Edit(//<置き場のパス>/**)` を足しておくとよい。

### 置き場の中身(例)

```
<置き場>/
  CLAUDE.md          読み方・書き方のルール(判断ログ・好みの書式、要約の更新)
  要約ノート.md      常に読み込む短い要約
  判断軸/
  判断ログ/
  好み/              領域ごとに1ノート
```

## インストール

```
claude plugin install self-clone@hiroki-plugins
```
