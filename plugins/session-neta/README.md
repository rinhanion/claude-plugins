# session-neta

Claude Code のセッションが終わるたびに、その作業内容を**ブログのネタ帳**としてローカルに自動で書き出す。
あとから `/session-neta` で在庫を見て、書きたいものを選んで [note-draft](../note-draft/README.md) に渡すと記事になる。

作業が終わると「何をやって、どこで詰まって、どう直したか」はトランスクリプトの中に埋もれて消えてしまう。
それを毎回自動で拾い上げておくためのプラグイン。

## 仕組み

```
セッション終了（SessionEnd）
      ↓  hooks/session-end.sh → scripts/harvest.mjs（LLM 呼び出しなし・数百ミリ秒）
~/blog-neta/sessions/2026-08-29-job-tracker-953c6266.md
      ↓  後日、書きたくなったときに
/session-neta  →  在庫一覧から1件選ぶ → 「なぜやったか」を補足
      ↓
note-draft（文体プロファイル STYLE.md）→ 確認 → note に下書き投稿
```

**自動化するのは素材の収集まで。** 記事の生成と note への投稿は必ず本人の確認を挟む
（note-api MCP には下書きの削除ツールがないため、投稿は取り消せない）。

## ネタ帳に入るもの

| 項目 | 内容 |
|---|---|
| タイトル | Claude Code が付けたセッションタイトル |
| やろうとしたこと | 最初に投げたプロンプト |
| 会話の流れ | 自分が書いたプロンプトだけを時刻付きで（ツール結果やスラッシュコマンドの出力は除外） |
| 触ったファイル | Edit / Write したファイル（使い捨てのスクラッチファイルは除く） |
| つまずき・エラー | 失敗したツール呼び出し。記事の山場になる部分 |
| git | commit / PR / Issue のタイトル |
| 実行したコマンド | ノイズ（`ls` `cat` 等）を落とした抜粋 |

`password` / `token` / `secret` / `api_key` や `gho_*` `sk-*` 風のトークンは書き出す前に伏字化される。

## 静かにしておくための工夫

- **中身のあるセッションだけ**ネタ帳にする。ファイル編集が1回以上、または自分の発言が3往復以上。
  調べものだけ・一発質問だけのセッションはスキップする。
- 何が起きても `exit 0`。セッションの終了を妨げない。
- ファイル名にセッション ID が入るので、同じセッションで複数回発火しても上書きで済む。

## 設定

| 環境変数 | 既定値 | 内容 |
|---|---|---|
| `BLOG_NETA_DIR` | `~/blog-neta` | ネタ帳の保存先。実ファイルは `<dir>/sessions/` に置かれる |

## 手動で実行する

進行中のセッションをその場でネタ帳にしたいときは、ハーベスタを直接叩ける。

```sh
node scripts/harvest.mjs --transcript ~/.claude/projects/-Users-rinkoro-projects-job-tracker/<session-id>.jsonl
```

生成されたファイルのパスが標準出力に出る（中身が薄いと判定された場合は何も出ない）。

## インストール

```
/plugin install session-neta@hiroki-plugins
```

有効化した時点で全プロジェクトのセッションが対象になる。
`~/.claude/settings.json` に自分でフックを書き足す必要はない。
