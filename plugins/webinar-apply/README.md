# webinar-apply

メールに届いたウェビナー案内から、興味のありそうなものを選んで参加申し込みを進めるプラグイン。[claude-plugins](../../README.md) マーケットプレイスの1つ。

## 何ができるか

- 「メールのウェビナー探して」「ウェビナー申し込んで」と伝えると、Gmail から直近のウェビナー案内を集め、関心に近い順に並べる
- チェックリストで選んだものだけ、申込フォームを確認画面まで自動で入力する
- 確定前に全件の確認画面をまとめて見せ、一括で了承を取ってから確定する
- ユーザーへの確認は「候補の選択」と「確定前の一括確認」の 2 回だけ

## 構成

| コンポーネント | 種類 | 役割 |
|---|---|---|
| `webinar-apply` | Skill | ウェビナー案内の収集・選択・申込フォーム入力・確定前確認 |

## セットアップ

- Gmail 連携(MCP)と、ブラウザ操作ツール(Claude Code の内蔵ブラウザ / Claude in Chrome / Playwright のいずれか)が必要
- ログインが必要なサイトは、利用者が自分でログインする(認証情報の自動入力はしない)

### 申込者プロファイル

氏名・メール・電話などの個人情報はこのリポジトリに含めない。実行時に次のファイルから読む。

```
~/.config/claude-profile/profile.md
```

初回の実行でファイルが無ければ、Claude がチャットで項目を質問し、保存の了承を得てから作成する(権限は `600`)。手で作る場合の雛形:

```markdown
- 氏名:
- ふりがな:
- メールアドレス:
- 電話番号:
- 会社名:
- 部署:
- 職種:
- 役職:
- 都道府県:
```

- ファイルは平文で保存される。リポジトリの外に置き、コミットしない
- ほかの申込系スキルでも同じファイルを共用できる

## 使い方の例

- 「メールのウェビナー探して」
- 「届いてるウェビナーで興味ありそうなの申し込んどいて」
- 「興味ありそうなセミナーある?」

## インストール

```
claude plugin marketplace add rinhanion/claude-plugins
claude plugin install webinar-apply@hiroki-plugins
```
